Firefox ekstenzija · Manifest V3

Od YouTube transkripta do sažetka

YT Summary AI preuzima tekst videa, filtrira sponzorske segmente i šalje sadržaj izabranom AI servisu. Jezik interfejsa i jezik odgovora biraju se zasebno.

Tok podataka

1. TranskriptYouTube titlovi, InnerTube ili tekst sa stranice.
2. FiltriranjeSponsorBlock rasponi i vremenske oznake.
3. AI odgovorGemini ili OpenRouter; dugi tekst deli se u delove.
4. RezultatSažetak, chat, kviz, promena detaljnosti i izvoz.

Podešavanje i upotreba

  1. U Firefoxu otvorite about:debugging#/runtime/this-firefox, izaberite „Load Temporary Add-on” i učitajte manifest.json.
  2. U ekstenziji izaberite Gemini ili OpenRouter i unesite odgovarajući API ključ.
  3. Za Gemini dostupni su gemini-3.7-flash i gemini-3.5-flash-lite. OpenRouter koristi model slug, podrazumevano openrouter/auto.
  4. Otvorite YouTube video, izaberite detaljnost, stil i jezik odgovora, pa pokrenite generisanje. Na stranici sa listom dostupna je i grupna obrada pronađenih videa.

Transkript mora da postoji. Ekstenzija ne transkribuje zvuk i ne garantuje dostupnost teksta za svaki video. Obrada liste obuhvata ID-jeve koje trenutno može da pronađe na stranici.

Dohvat i filtriranje

Na aktivnom videu samostalna funkcija radi u glavnom YouTube kontekstu (world: "MAIN"). Dva API pokušaja pokreću se paralelno, a DOM pokušaj ima kratak odloženi početak. Prvi uspešan rezultat završava dohvat; preostali pokušaji se prekidaju. Za grupnu obradu postoji i direktan dohvat, uz rezervni YouTube prozor kada je potreban.

SponsorBlock je dopunski izvor: nedostupan servis ne sprečava sažimanje. Tekst titla ne može precizno da se podeli po izgovorenim rečima jer nemamo njihove vremenske oznake. Pravilo za izbor segmenata i obračun vremena opisano je u tehničkoj dokumentaciji.

Podaci i troškovi

  • API ključ i podešavanja čuvaju se u lokalnom skladištu ekstenzije. Ključ se šalje izabranom AI provajderu kao deo autentifikacije.
  • Transkript i vaša pitanja šalju se Gemini ili OpenRouter servisu radi generisanja odgovora; SponsorBlock dobija ID videa.
  • Prikazana potrošnja zasniva se na podacima API odgovora. Gemini cena je procena plaćenog standardnog tarifa; besplatni nivo, keširanje i uslovi naloga mogu da promene stvarni račun.
  • AI odgovor može sadržati greške. Vremenske oznake otvaraju izvorni video i pomažu proveri tvrdnji.

Razvoj i provere

Instalirajte razvojne zavisnosti komandom npm ci. npm test -- --runInBand proverava JavaScript i Jest testove; npm run lint proverava ekstenziju, a npm run package pravi XPI paket.

Struktura modula, skladište i ograničenja opisani su u tehničkoj dokumentaciji. Rezultati detaljnog pregleda nalaze se u HTML izveštaju.

Dokumentacija radi lokalno, bez spoljašnjih skripti i CDN zavisnosti.
